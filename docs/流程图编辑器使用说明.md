# 流程图编辑器使用说明

本文只写**已经实现并在本仓库可用**的功能。看不到的能力就是没有做，不要按本文以外的方式去试。

## 1. 打开

```bash
pnpm install
pnpm dev
```

浏览器打开终端里给出的地址（默认 `http://localhost:5173`）。左上角在 **思维导图** 与 **流程图** 两个模式之间切换；流程图模式默认载入内置的示例图（WMS 收货入库流程）。

## 2. 建节点（从左栏拖）

左下角有一个「流程节点」方块，**拖到画布的某个格子上松手**：

- 落在空格子 → 节点就放那儿；
- 该格已经有人 → 自动**往下**找最近的空格子，下到底再往上找；
- 编号自动接着现有最大号排（示例图有 A01–A21，下一个就是 A22）。

## 3. 移动 / 换泳道（直接拖节点）

拖动节点，松手后会**吸附到格子上**。**横向拖过泳道分界线，就等于改了它的归属泳道**，节点颜色会跟着新泳道变（配色按泳道来，不能单独改一个节点的颜色）。

拖到格子外面（比如拖到左侧步骤号列或表头区域）→ 节点弹回原处。

## 4. 改文字

**双击节点**，会在节点上弹出一个输入框：

- 回车或点别处提交；
- `Esc` 取消；
- 文字**换行会让节点自动变高**，不需要手动调大小。

## 5. 连线

鼠标移到节点上会出现锚点，**从锚点拖到目标节点**即可建线（默认棕色实线）。

**注意**：同一对节点之间只能有一条线，重复拖不会叠加第二条。反向（A→B 与 B→A）是两条不同的线，可以共存。

## 6. 改连线标签

**双击连线**，在弹出框里改文字（示例图里的「合格改刀料」「不合格品」「数量不足」就是这类标签）。

## 7. 改泳道名

**双击泳道表头**，在弹出框里改名。

## 8. 删除

选中元素后按 `Delete`。**删节点会连带删掉挂在它上面的连线**（不会留下指向不存在节点的悬空线）。

## 9. 撤销 / 重做

- 撤销：`Ctrl+Z`
- 重做：`Ctrl+Shift+Z`

撤销是**文档级**的：它回退的是整张图的数据，所以画布和实际数据永远一致。

## 10. 多选

按住 `Shift` 点选多个元素。

## 11. 泳道与步骤（右上角工具栏）

| 按钮 | 行为 |
|---|---|
| 添加泳道 | 在最右侧追加一列，配色按五色循环，宽度取现有列的平均值。**已有节点不会乱动** |
| 删除末条泳道 | 只删最右边那条。**该泳道里还有节点时会拒绝并提示**（先把节点移走或删掉） |
| 步骤 + / 步骤 − | 增删行带。**减少步骤不会删掉任何节点**：超出范围的节点会自动上移；若格子确实不够（每条泳道的节点数 > 新步骤数），会**拒绝这次操作并提示**，而不是把节点堆在一起 |

## 12. 保存 / 导入 / 导出

- **自动保存**：编辑会自动存进浏览器本地（localStorage），刷新不丢。
- **导出 JSON**：把整张图存成一个 `.json` 文件。
- **导入 JSON**：从文件恢复。文件坏掉时会给出可读的错误提示，不会白屏，也不会覆盖当前内容。
- **重置为示例**：清掉本地存储、回到内置示例图（会先确认，因为会丢掉未导出的改动）。

## 13. 导出图片

右上角「导出 PNG」，导出的是**整张图**（不是当前视口看到的那一块）。

## 14. 边界与限制

- 数据只存在**这台浏览器**里。清浏览器数据会丢，换机器请用 JSON 导出/导入。
- **连线走线是自动的**：走「水平 → 垂直 → 水平」的肘形，拐点位置固定，**不能手动拖拐点**。
- **泳道宽度、泳道配色、泳道顺序改不了**。要改就直接编辑导出的 JSON 再导入（`lanes` 数组里每项有 `width` 与 `color`，`color` 取值 `blue` / `orange` / `green` / `purple` / `red`）。
- 节点默认宽度由泳道宽度决定。若要在**同一格里并排放两个节点**（示例图的 A13/A14 就是这样），需要在 JSON 里给这两个节点各自声明 `width`（收窄）与 `offsetX`（左右错开），例如：

```json
{ "id": "A13", "text": "改刀料\n称重·计数\n插盘", "laneId": "lane-prep", "step": 6,
  "kind": "process", "width": 88, "offsetX": -47 }
```

## 手工验收清单

改完代码后按这份清单过一遍（`pnpm test && pnpm build` 先要全绿）：

- [ ] 切换两个模式都正常，思维导图仍能正确取景
- [ ] 从左栏拖节点：落空格子放那儿；落占用格子往下顺延
- [ ] 拖动节点吸附到格子；跨泳道拖，配色跟着变
- [ ] 节点拖到格子外 → 弹回原处
- [ ] 双击改节点文字：回车提交、Esc 取消，换行后高度变化
- [ ] 双击连线改标签；双击表头改泳道名
- [ ] 选中后 Delete 删除；删节点连带删掉它的连线
- [ ] 从锚点拖出连线；同一对节点重复拖不产生第二条线
- [ ] `Ctrl+Z` / `Ctrl+Shift+Z` 撤销重做，且**编辑时视口不跳**
- [ ] `Shift` 多选
- [ ] 「添加泳道」后已有节点不错位
- [ ] 往有节点的泳道删 → 被拒绝且有提示
- [ ] 「步骤 −」减到很小 → **节点一个都没少**；减到放不下 → 被拒绝且有提示
- [ ] 导出 JSON → 导入回来是同一张图
- [ ] 「导出 PNG」是整张图，不是只截视口
- [ ] 刷新浏览器，改动还在
