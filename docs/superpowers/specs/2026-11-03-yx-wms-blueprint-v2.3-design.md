### 3.1 各流程数据同步规则

- 泳道按流程实际角色设置；ERP 相关流程必须包含「金蝶 ERP」或「ERP/MES」泳道。
- 异常分支统一三段式：`失败 → 自动重试 3 次 → 仍失败告警并转人工`。
- 审计动作写入步骤描述（「记录操作日志」/「审计留痕」）。
- 异常文案尽量复用 `gen_wms_figs_mmd.py` 已有的分支标签白名单；若确需新标签，**允许扩展 `ERR_LABELS` / `OK_LABELS`**，并在验收报告注明。

### 3.2 「未落地」的处理（2026-11-03 裁决）

- **设计中有、尚未落地的环节也写进流程**（如 XT-001 的报废回写金蝶、SB-002 的设备调度闭环）。
- 只排除两种：① 已移出项目范围的（采购/检验/线边柜）；② 明确拍板不做的（XT-001 退货）。
- 一律不写「未实现/后续」字样。
