# 永鑫WMS 前端演示 · 手工测试用例（10 分钟）

- 版本：2026-10-30
- 用途：**可对外展示**的 10 分钟全量走查脚本，配套当前开发进度（16 条蓝图流程已交付 12 条）
- 环境：本机（后端 8081 / 前端 3100），账号 `admin / 123456`（验证码随便填）
- 三条硬约束（本用例**全程满足**）：
  1. **不碰金蝶 ERP**：不点任何「同步金蝶 / 重试同步 / 对账 ERP」按钮，不触发回写
  2. **不做高风险操作**：不新建、不提交、不下发、不确认、不关单、不删业务单据、不改系统配置
  3. **产生的痕迹可还原**：本用例只会产生「导出任务 + 文件」和「字号设置」，两者都有还原步骤（§4）

## 2. 演示路线（9 站，约 9 分钟）

### 第 1 站｜生产工单（1.5 分钟）`菜单：入库管理 → 生产工单`

| 操作 | 预期结果 |
| --- | --- |
| 打开页面 | 列表 25 条工单，列含工单号 `MO10126…`、物料、计划数量、状态、同步状态 |
| 看「状态」列 | 多数是「已下达」——这是从金蝶 `PRD_MO` 同步过来的真实工单 |
| 上方搜索区「工单号」填 `MO1012615492` → 点「查询」 | 只剩 1 条，物料 `ZA.00.09011.085027010501.B026` |

> 本页顶部有个「从ERP同步」按钮——**演示时不要点**（会调金蝶拉单）。
> 亮点：工单同步是**增量 + 失败重试**，单号与金蝶 1:1，不另造编码。

### 第 2 站｜生产入库（1.5 分钟）`菜单：入库管理 → 生产入库`

| 操作 | 预期结果 |
| --- | --- |
| 打开页面 | 列表 554 条，状态分布含「草稿」「已入库」 |
| 上方搜索区「状态」选「草稿」→ 查询 | 出现一批「工序汇报草稿」，单号形如 `GXHB659871-0-10` |
| 点任一行「详情」 | 抽屉显示：物料、数量、批次、入库库位、ERP 单据号（草稿显示 GXHB 汇报单号） |

⚠️ **本页只点「详情」**。以下按钮**不要点**（会写 ERP 或改状态）：
「推进」「重新下发」「转人工完成」「关单」「同步金蝶」「对账 ERP」。

> 亮点：这就是「半成品进 ERP」的方案 B——车间在金蝶做工序汇报，WMS 只记账，不重复开单。

### 第 3 站｜库区与库位（1 分钟）`菜单：入库管理/基础数据 → 库区与库位`

| 操作 | 预期结果 |
| --- | --- |
| 打开「库区」页 | 198 个仓库，编码 `D.01`/`D.02`/`W.17`…，**与金蝶仓库编码 1:1** |
| 切到「库位」页 | 152 个库位，立库 `LB-R01-*` 与敏捷仓 `MJ-*`，含状态列（空闲/占用） |

> 亮点：仓库主数据全量同步金蝶，不做二级编码映射，对账不用翻译。

### 第 4 站｜物料与分类（1 分钟）`菜单：基础数据 → 物料与分类`

| 操作 | 预期结果 |
| --- | --- |
| 打开页面 | 物料总数 4.6 万+，第一页显示编码、名称、规格、单位 |
| 搜索 `ZA.00.09011` | 命中「非涂层-银铜焊接（C+B）-ST型钻咀双刃双槽-自制」 |

> 亮点：4.6 万物料从金蝶同步；产品类型（半成品/成品）由**入库来源**判定，不靠人工维护。

### 第 5 站｜库存台账（2 分钟）`菜单：库存查询 → 库存台账` ★ 本次重点

| 操作 | 预期结果 |
| --- | --- |
| 打开页面 | 「库存明细」表为空时提示「未找到匹配的库存记录」；下方是「我的导出任务」 |
| 直接点「导出 Excel」 | 弹出「导出任务已提交」，任务列表出现一行：状态「排队中/生成中」→ 数秒后变「成功」，行数 0（当前账面无库存） |
| 等状态变「成功」后点「下载」 | 浏览器下载 `库存台账_*.xlsx`，用 Excel 打开可见表头 | 
| 点该任务行的「删除」 | 确认框提示「生成的文件也会一并删除」→ 确定后任务消失 |

> 亮点（技术含量最高的一站）：
> - **几十万行也能导**：后台异步生成 + 流式写盘，页面不卡；轮询只拉第一页
> - **只导本人的**：任务仅导出人可见、可重下
> - **7 天自动清理**：文件到期由定时任务删，不会堆磁盘
> - 当前采用**实时快照**，历史时点结存（如「9 月 30 日结存」）为后续版本

### 第 6 站｜批次追溯（1 分钟）`菜单：批次追溯 → 批次查询`

| 操作 | 预期结果 |
| --- | --- |
| 输入批号 `KD-MO1012615733` 查询 | 返回该批次的库存行/流水（当前库存为 0，页面会如实展示空结果并给提示） |
| 换一个批号 `KD-MO1012615790` | 同上，行为一致（不报错、不白屏） |

> 亮点：批次是一等公民——入库即建批号，出库按批号分配，ERP 侧批号主档缺失时会自动补建。

### 第 7 站｜出库单（1 分钟）`菜单：出库管理 → 出库单`

| 操作 | 预期结果 |
| --- | --- |
| 打开页面 | 列表为空（已清理测试数据），空态提示正常 |
| 看搜索区「出库类型」下拉 | 含「生产领料 / 销售出库 / 外协出库 / 样品出库」四类 |
| 看顶部按钮组（**只看不点**） | 「新建领料 / 新建销售 / 同步委外订单 / 生成领料待办 / 生成销售待办 / 新建样品」 |

⚠️ **本页所有顶部按钮都不要点**：三个「生成/同步」按钮会**直接调金蝶接口**，其余会建单。
本页只演示「类型齐全 + 空态正常」，1 分钟看完即走。

> 亮点：出库不是「手工填单」，销售出库由**金蝶发货通知单**生成待办，领料由**金蝶用料清单**生成待办，
> 仓管员只做扫码执行与确认。

### 第 8 站｜设备管理（1 分钟）`菜单：基础数据 → 设备管理`

| 操作 | 预期结果 |
| --- | --- |
| 打开页面 | 4 台设备（立体库 WCS / 敏捷仓 RMS），含状态、最近心跳 |
| 点「告警记录」或阈值入口 | 展示设备离线阈值 60 秒、告警节流 30 分钟 |

> 亮点：设备离线扫描是定时任务，离线上报会走站内信，不靠人盯。

### 第 9 站｜文字缩放（1.5 分钟）`菜单：系统配置 → 文字缩放`

| 操作 | 预期结果 |
| --- | --- |
| 把「文字缩放」拉到 **150%** | 全站字号变大，**按钮/输入框高度同步变大**（文字不压边）、**表格列宽等比放大**（表头不折行，横向滚动承接） |
| 打开「库存台账」页看一眼 | 表头「仓库状态」「首次入库时间」保持单行，操作按钮完整（这是本轮刚修的） |
| 拉回 **100%** | 恢复初始视觉 |

> 亮点：工厂大屏/老花眼场景常用；字号与控件高度是两个独立 token，只改字号会压边——这条坑我们踩过并修了。

## 4. 还原步骤（演示后必做，30 秒）

| 产生的痕迹 | 还原动作 |
| --- | --- |
| 导出任务 + 下载的文件 | 在「我的导出任务」点「删除」（文件一并删除）。**即使不删，7 天后定时任务也会自动清理** |
| 下载到本地的 xlsx | 直接从下载目录删掉 |
| 文字缩放被改成 150% | 拉回 100%（设置存 localStorage，只影响本浏览器） |
| 其它 | 本用例不产生任何业务数据；若误点了「删除」类按钮，按 `§5` 处置 |

> 若演示中误触了写操作，用 `git status` 确认无代码改动，业务数据按「待办清单」里的清理流程处理；
> **本用例设计上不触碰任何写接口**。

## 7. 演示失败的兜底

| 现象 | 处置 |
| --- | --- |
| 页面 404 或接口报「路径不存在」 | 后端 jar 是旧的：`bash /d/tools/m.sh -P dev -pl jeecg-boot-module/jeecg-boot-module-wms install -DskipTests` 后**重启后端** |
| 列表一直转圈 | 后端未启动（8081）；前端代理见 `.env.development.local` |
| 导出一直「排队中」 | 看后端日志是否有导出线程异常；重试按钮可重新排队 |
| 文字缩放后页面错位 | 拉回 100%；若是新页面，按历史经验该页面可能没接 `scaleTableColumns` |
