# 永鑫WMS 前端演示 · 对照操作单

- 环境：本机（前端 3100 / 后端 8081），账号 `admin / 123456`（验证码随便填）
- 用法：演示时**照着「点什么」一列往下点**，「看到什么」一列核对；打 ⛔ 的地方停手
- 三条硬约束（本单全程满足）
  1. **不碰金蝶 ERP**：不点任何同步/生成类按钮
  2. **不做高风险操作**：不新建、不提交、不下发、不确认、不关单、不删业务单据、不改配置
  3. **痕迹可还原**：只产生「导出任务+文件」和「字号设置」，见 §4

### 站 5 · 库存台账 ★重点　`库存查询 → 库存台账`

| 点什么 | 看到什么 |
| --- | --- |
| 打开页面 | 「库存明细」空态提示「未找到匹配的库存记录」；下方是「我的导出任务」 |
| 点「导出 Excel」 | 提示「导出任务已提交」，任务行从「排队中/生成中」数秒后变「成功」，行数 0（当前无库存） |

> 亮点话术：
> - 几十万行也能导：后台异步生成、流式写盘，页面不卡
> - 只导本人的：任务仅导出人可见、可重下
> - 7 天自动清理，不堆磁盘
> - 当前是实时快照；历史时点结存（如「9 月 30 日结存」）为后续版本

## 3. 生产入库三列状态怎么读（站 2 备用）

表格里有**三列状态，是三个独立的时钟**，不是一条时间线。分开显示是为了异常时一眼看出「**货到了、账没到**」。

| 列 | 含义 | 取值 |
| --- | --- | --- |
| **状态** | 实物在哪 | 草稿 → 待上架 → 执行中 → 已入库；异常分支「异常待人工」；终态「已关闭」 |
| **任务状态** | 设备干到哪 | 未下发 → 已受理 → 执行中 → 已完成；失败分支「失败」 |
| **同步状态** | ERP 记账没有 | 待同步 → 同步中 → 同步成功 / 同步失败；**无需同步**（不参与回写） |

常见组合：

| 组合 | 含义 | 是否正常 |
| --- | --- | --- |
| 草稿 + 未下发 + 无需同步 | 工序汇报草稿，还没推进 | ✅ 正常（方案 B 不回写） |
| 待上架 + 已受理 + 无需同步 | 货在等设备搬运，实物没入库前不该开 ERP 单 | ✅ 正常（长期不动则为设备任务没回执） |
| 已入库 + 已完成 + 同步成功 | 实物与账务都完成 | ✅ 闭环 |
| 已入库 + 已完成 + 同步失败 | **货进了 WMS，但金蝶写不进去**（业务口径/ERP 拒绝） | ❌ 需人工处理 |

> 「无需同步」两种来源：①有良品的单在上架完成前 ②工序汇报来源（方案 B，ERP 由车间汇报，WMS 不重复开单）。

## 5. ⛔ 禁点清单

| 页面 | 禁点 | 后果 |
| --- | --- | --- |
| 生产工单 | 从ERP同步 | 调金蝶 `PRD_MO` |
| 生产入库 | 推进 / 重新下发 / 转人工完成 / 关单 | 占库位、下发任务、改状态 |
| 生产入库 | 同步金蝶 / 对账 ERP / 重试同步 | 调金蝶接口 |
| 出库单 | 生成领料待办 / 生成销售待办 / 同步委外订单 / 新建… | 前三个直接调金蝶，其余建单 |
| 出库单 | 分配 / 下发 / 复核 / 确认出库 / 关闭 | 扣库存、下发任务、回写 ERP |
| 调拨 / 盘点 | 新建 / 提交 / 确认 | 产生单据与库存变动 |
| 物料 / 仓库 / 库位 / 设备 | 新增 / 编辑 / 删除 | 改主数据 |
| 系统配置 | 任何「保存」 | 改 `sync.auto` 等开关影响全局 |

## 7. 出问题怎么办

| 现象 | 处置 |
| --- | --- |
| 页面 404 / 提示「路径不存在」 | 后端 jar 旧：`bash /d/tools/m.sh -P dev -pl jeecg-boot-module/jeecg-boot-module-wms install -DskipTests` 后重启后端 |
| 列表一直转圈 | 后端没起（8081）；前端代理见 `.env.development.local` |
| 导出一直「排队中」 | 看后端日志导出线程；点任务行「重试」重新排队 |
| 文字缩放后错位 | 拉回 100% |
