## 3. 抽查核实的代表性结论（防 agent 幻觉）

- `WmsInventoryMapper.xml` 四条 UPDATE 条件与 agent 描述**逐字一致**（实测读 XML）
- `deductLocked==0 → patchOrderStatus(EXCEPTION) + alert + throw` 分支真实存在（`WmsOutboundServiceImpl:591-597`）

- 六个主数据服务 `removeBatch` 均带 `@Transactional(rollbackFor = Exception.class)`（反射测试通过即证明）
