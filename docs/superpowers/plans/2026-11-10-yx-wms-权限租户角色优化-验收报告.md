1. 计数基准修正：plan 初稿 108/88 是未滤 del_flag 的历史全量（含 15 个停用线边柜域的已删权限点），活跃 `wms:%` 权限点实为 93，期望计数改为 93/93/73/30/6/8。若错：计数断言口径错，授权量级不变。
2. 菜单子树授权泄漏按钮：递归 CTE 未滤 menu_type，operator 实测 79 大于矩阵 30（拿到物料/供应商维护按钮）。修正：子树只授 menu_type IN (0,1)，按钮只走矩阵精确码。若错：按钮越权，spec 分离原则被破坏。
3. 授权行 id 确定性：`sys_role_permission` 无唯一键，UUID 主键重跑必插重复行、幂等不成立。改为 `'192'||SUBSTR(permission_id,4)||角色位`（admin=A，901~905=1~5）。若错：需去重脚本，代价一次 SQL。
4. 停用域豁免：`wms:inbound:*`（consigned 除外）与 `wms:order:*` 共 11 个注解码无权限点，是停用线边柜域的预期状态；检查脚本显式白名单豁免并逐次打印，恢复该域时须删豁免。若错：真缺口被掩盖，靠输出 ℹ 行可见性兜底。
5. 测试账号密码：SQL 复制 admin 哈希不可行（PBE 以用户名为密钥），改走 `/sys/user/add` 由后端加密；Git Bash 控制台 GBK 压坏中文 JSON，realname 用 ASCII。若错：账号无法登录，重建即可。
6. 断言表修正：wms_t_admin 挂的是 wms_admin 业务角色而非平台 admin 用户，按矩阵只见 WMS 子树；初稿断言混同两者，修正后 5/5 PASS。
