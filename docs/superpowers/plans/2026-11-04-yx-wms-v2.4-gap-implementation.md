# 蓝图 V2.4 差距落地 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按蓝图 V2.4 补齐代码：受托库存模型、RK-001 外购/受托原材料入库（大改小走生产入库、段差棒直入）、RK-005 两类不良来源、CK-001 领料动作细化。

**Architecture:** 在现有 `wms_inventory` 上加所有权与受托方两维并重建唯一键；复用采购入库骨架与生产入库/领料通道；新增改制单与不良记录两张业务表；金蝶侧新增可配置的单据 Reader/Writer（formId 来自配置，未配置即显式失败）。

**Tech Stack:** Spring Boot 4 / MyBatis-Plus / Quartz / Flyway / AutoPoi / Vue 3 + Ant Design Vue。

**Spec:** `docs/superpowers/specs/2026-11-04-yx-wms-v2.4-gap-implementation-design.md`

## Global Constraints

- Maven 走 `bash /d/tools/m.sh -P dev ...`，测试模块 `-pl jeecg-boot-module/jeecg-boot-module-wms`；命令从 `jeecg-boot/`（reactor 根）执行。
- 提交 `feat(wms):` / `fix(wms):`，从仓库根提交，末尾 `Co-Authored-By: Claude Code <noreply@anthropic.com>`。
- 无 MetaObjectHandler：审计字段用 `WmsUtils.fillCreate/fillUpdate` 显式写入；异步/无登录上下文用显式 operator。
- 统一 `Result<T>`；写端点 `@RequiresPermissions` + try/catch `Result.error(e.getMessage())`；DTO 日期字段 `@DateTimeFormat`。
- 状态/类型用中文常量进 `WmsConstants`；配置项加 `WmsConfigKey`。
- 金蝶：`FBaseQty`、`TopRowCount=0 + Limit`、组织 `101`；不传 `FBillNo`，回存 ERP 单号。
- 受托库存：`ownership_type=CONSIGNED` 必须带 `consignor_id`（供应商 ID）；自有为空。
- 大改小原材料**不入 WMS 库存**；投入不回写 `PRD_PickMtrl`（ERP 生产订单负责）。
- 员工身份取当前登录账号，不做下拉/读卡器。
- 金蝶 formId 未确认前，Reader/Writer 必须在配置缺失时抛明确异常，不得静默返回空。

## Review Focus

1. **自有/受托库存串账**：默认查询、可用量、预警、盘点、调拨必须只取 `OWNED`；受托只在显式筛选/受托场景出现 → T3 测试。
2. **唯一键重建**：存量重复数据必须先校验，失败中止迁移 → T1 迁移守卫测试。
3. **受托方为空**：`CONSIGNED` 行 `consignor_id` 为空必须拒绝写入 → T3/T5 测试。
4. **大改小重复执行**：改制单只能完成一次，重复完成不得生成第二张生产入库单 → T6 测试。
5. **formId 缺失**：配置为空时必须显式报错，不能返回空 map 产生假差异/假成功 → T4 测试。
