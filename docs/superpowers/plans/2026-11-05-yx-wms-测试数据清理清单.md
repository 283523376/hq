### 7.3 ⚠️ 真实物料被改动 —— 必须还原

**物料 `YY.3011.9954.C0002`（外购复合原料-精磨-420J2+AF308）被我从 ERP 原分类改到了测试分类。**

```sql
-- 当前（错误状态）
SELECT id, material_code, unit, category_id FROM wms_material WHERE material_code='YY.3011.9954.C0002';
-- 2115354438552891393 / YY.3011.9954.C0002 / zhi / 9999000000000000001（测试分类）
```

**还原前必须先知道它的原分类。** 原值未记录，两条恢复路径：

1. **推荐：从 ERP 重新同步物料主数据**（金蝶侧分类是权威）
   - 后端菜单「物料管理 → 从 ERP 同步」，或调同步接口
   - 同步后会按 `material_code` upsert，分类与单位一并覆盖
2. 手工还原：先查金蝶该物料的物料分组，再对应到 WMS 分类

**单位 `zhi` 不需要还原** —— 那是从金蝶 BD_MATERIAL 查到的真实单位（支），本来就该是这个值。

> ⚠️ 注意：**必须在删掉测试分类（7.2）之前还原**，否则 `category_id` 会变成悬空引用。

顺序应为：7.3 还原真实物料 → 7.2 删测试分类 → 7.1 删测试物料。
