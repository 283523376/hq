## C. 已修复但有残留取舍（供知悉，非待办）

| 项 | 残留 |
| --- | --- |
| 删除语义统一为**删除时间戳**（7 张表） | `deleted_at` 的 `delval` 用 MySQL 方言 `UNIX_TIMESTAMP(NOW(3)) * 1000`；换数据库需抽象。另：同一编码两行在**同一毫秒**被删会撞索引（实际不可达，但非数学证明） |
| 库区维度可自由增减 | **缩维后**已存在的库位可能落在新声明之外 —— 系统**不拦截**，只在库区树/详情显示「有 N 个库位位于当前维度之外」 |
| 编辑库区的调用契约 | 表单必须提交全部三个维度字段；**漏传即视为「清空」**。当前唯一调用方（库区编辑弹窗）始终提交三项，但新调用方做部分更新会静默清空维度 |
| 批量生成不做整体回滚 | 某批失败即停止，返回已生成数 + 续做方式；靠唯一索引 + `INSERT IGNORE` 幂等续做 |
