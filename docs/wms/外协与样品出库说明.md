# 外协出库与样品出库 说明

> 设计依据：`docs/superpowers/specs/2026-10-26-yx-wms-outbound-subcontract-sample-stocktake-design.md` §5.1 / §5.2
> 两者都复用既有出库骨架（`wms_outbound_order/detail/allocation`），仅靠 `outbound_type` 区分。

## 1. 外协出库（本期为「骨架」）

**做什么**：从金蝶 `SUB_SUBREQORDER`（生产制造→委外管理→委外订单）拉取已审核订单，
按单号 upsert 成 WMS **只读草稿**。

**不做什么**（本期边界）：
- 不展开委外 BOM 子项 —— 委外领料回写的对象是 BOM 展开的子项，而子项多为**尚未纳入项目范围的原材料**（外部依赖 E6）；
- 不拣货、不下发设备、不回写 `SUB_PickMtrl`。

**配置**：

```yaml
wms:
  sync:
    erp:
      kingdee:
        subcontract:
          org-filter: "FPrdOrgId.FNumber='101'"   # 原始 filter 片段；空 = 不同步
          pick-status-done: ""                     # FPickMtrlStatus 表示已领料完成的值；空 = 不自动作废
```

`org-filter` 留空即拒绝同步——测试账套里 200+ 张委外单属 org 100 历史组织，
不带组织过滤会把历史数据灌进来。

**作废规则**：`pick-status-done` 配置后，金蝶行 `FPickMtrlStatus` 命中该值的草稿会被置「已关闭」，
原因写「ERP 已领料完成」。

**入口**：出库页工具栏「同步委外订单」→ `POST /wms/outbound/sync-subcontract?top=50`。

## 2. 样品出库

**做什么**：手工建单（单物料单批次）→ 审批 → 拣货 → 扣库存；出库类型 `样品出库`，单号前缀 `YP`。
**不绑定**工单与销售订单——这两条回写链路都不适用。

**回写**：适配器 `IWmsSampleOutboundErpWriter`，本期**明确报错、不发请求**：
- `wms.outbound.sample.stock-code` 未配置 → 报「未配置（E5）」；
- 即使配置了，单据形态（调拨单 `STK_TransferDirect` 还是其他出库单 `STK_MisDelivery`）仍待客户确认 → 报「形态待确认（E5）」。

测试期建议配 `YF.01`（101 组织现有研发仓）；生产期新仓建成后只改配置。

**入口**：出库页「新建样品」→ `POST /wms/outbound/sample`。

## 3. 外部依赖

| 编号 | 待办 | 就位后动作 |
|---|---|---|
| E4 | 确认委外订单的组织字段名 | 配 `subcontract.org-filter`，外协同步即可真实拉单 |
| E5 | 确认样品回写的单据形态 | 在 `WmsSampleOutboundErpWriterImpl` 里接 `STK_TransferDirect` 或 `STK_MisDelivery` |
| E6 | 原材料纳入项目范围 | 另立 spec 补外协 BOM 子项明细、拣货与 `SUB_PickMtrl` 回写 |

## 4. 验证方法

```bash
# 外协：org-filter 未配置时应零查询、返回「未配置组织过滤」
curl -X POST "http://localhost:8081/jeecg-boot/wms/outbound/sync-subcontract?top=10" -H "X-Access-Token: <token>"

# 样品：建单后查库
"/c/Program Files/MySQL/MySQL Server 8.0/bin/mysql.exe" -uroot -proot yongxin_wms -e \
"SELECT outbound_no,outbound_type,status,work_order_no,sales_order_no FROM wms_outbound_order WHERE outbound_type IN ('外协出库','样品出库') ORDER BY create_time DESC LIMIT 5;"
```

预期：外协草稿 `status=草稿`、`work_order_no`/`sales_order_no` 均为空；
样品单 `status=待分配`、同样两列为空。
