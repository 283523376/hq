## 1. 背景与目标

客户要求在 WMS 内统一打印 12 类单据（库存 4、生产 3、委外 3、销售 2）。2026-11-09 客户定稿了其中 **7 类**的打印样式，要求按给定样式打印；其余 5 类样式待定。本设计覆盖打印模块的整体架构 + 7 类定稿模板的落地。

口径（2026-11-09 与客户确认）：
- 打印操作**全部在 WMS**；WMS 本地已有单据直接调出打印，没有的单据类型按单号从金蝶同步后打印。
- 输出走**浏览器打印预览**（HTML 模板渲染 → 打印对话框，可另存 PDF），横向纸张。
- 本期**不留打印记录**，架构预留留痕扩展点。
- 与 SB-001 口径一致：金蝶侧**只读**，不做任何写账操作。

## 3. 架构

### 3.1 后端（jeecg-boot-module-wms，`print` 包）

```
controller/WmsPrintController.java        # /wms/print/**
service/IWmsPrintService.java + impl      # 查单、组装打印数据（VO）
dto/WmsPrintQueryDTO.java                 # billType + billNo
vo/WmsPrintDataVO.java                    # 统一打印数据载荷（见 3.4）
sync/IWmsKingdeePrintReader.java + Impl   # 按类型查金蝶单据（ExecuteBillQuery，只读）
entity/WmsPrintDocument.java              # 金蝶来源单据的只读快照
mapper/WmsPrintDocumentMapper.java
```

- **快照表 `wms_print_document`**（Flyway `V3.9.5_52__wms_print_document.sql`）：存**金蝶来源**的 6 类（其他出入库、委外领料、销售退货、**盘盈/盘亏**——T1 数据源拍板后并入）；`bill_type` + `erp_bill_no` 唯一，payload 存查询原文（JSON），查询即 upsert 刷新。**失败路径拍板（设计者定）**：查询时先打金蝶，成功则刷新快照并打印新数据；金蝶失败但**已有快照** → 回退快照打印，预览页顶部醒目标注「金蝶暂不可达，本次预览为 {快照时间} 的数据」；**从未成功过（无快照）** → 显式报错。销售出库（本地 XS 单 + 金蝶补价税）维持本地实时组装，金蝶失败时价税留空并提示，不阻断。
- **权限**：新权限码 `wms:print:list`（工作台查询/打印一个权限码，与台账查询同口径）。
- **审计**：查询端点带 `@WmsAudit`（XT-002 口径，通道=UI）。

### 3.2 金蝶查询（只读）

- 复用 `WmsKingdeeFormClient`（登录/ExecuteBillQuery/View 封装、text/plain 坑已处理）。
- 5 个新增查询的 formId 与字段清单是 builder 的第一个落点，方法照旧：`BOS_BillType` 反查 formId → 在线控制台（BOS_HtmlConsole）核对字段可查询性 → ExecuteBillQuery 必须包 `{"data":…}`（项目记忆的既有坑）。预期 formId：`STK_MisDelivery` / `STK_MISCELLANEOUS` / `SUB_PickMtrl` / `SAL_OUTSTOCK`（已有）/ `SAL_RETURNSTOCK`。
- 金蝶未启用（`KINGDEE_ERP_ENABLED=false`）或查询失败：显式报错文案，与现有 Reader 一致。

### 3.3 前端（`views/wms/print/`）

- 新一级菜单「单据打印」（打印工作台）：左侧/顶部 12 类单据页签；5 类待定置灰 + 「样式待定」提示。
- 流程：选类型 → 输入/选择单号（本地类型下拉查本地单据；金蝶类型输单号）→ 查询 → 预览（`PrintPreview.vue` 内嵌对应模板组件）→ 打印按钮（`window.print()`，`@media print` 只输出预览区）。
- 7 个模板组件：`templates/ProfitListPrint.vue`（盘盈/盘亏共用，数量列标题随类型切换）、`MiscDeliveryPrint.vue`、`MiscInstockPrint.vue`、`SubcontractPickPrint.vue`、`SalesOutstockPrint.vue`、`SalesReturnPrint.vue`。模板即版式：`@page { size: A4 landscape }`，固定行数补空行（样单风格），合计/签名区/公司信息块按样单复刻。

### 3.4 打印数据载荷（`WmsPrintDataVO`）

统一结构，模板只认 VO 不认单据表：

```json
{
  "billType": "MISC_DELIVERY",
  "title": "其他出库单",
  "erpBillNo": "QTCK10126110327",
  "headers":  { "领用类型": "配件耗材领用单", "部门": "PCB非标车间", "日期": "2026/11/9" },
  "columns":  ["序号", "物料名称", "规格型号", "物料编码", "单位", "数量", "备注"],
  "pages":    [ [ ["1", "磨料", "开槽砂轮*…", "Y.P.008.0101", "块", "1", ""] ],
                [ ["2", "…", "…", "…", "块", "1", ""] ] ],
  "rowsPerPage": 12,
  "totalPages": 2,
  "totalsOnLastPage": { "数量": "2" },
  "footers":  [ "审核：谭桂芳", "仓管员：谭桂芳", "领料：唐兵" ],
  "extras":   { "联次行": ["白色：存根","红色：回单","黄联：仓库","绿联：客户"], "公司信息块": ["…"] }
}
```

**分页拍板（设计者定）**：`rows` 改为 `pages`（后端按 `rowsPerPage` 固定行数切段），每页重复表头；**合计只在末页**（单页时即唯一页）；`第x页，共y页` 由后端算好放进渲染上下文，前端模板不自行分页。空行补齐只作用于最后一页（样单风格：不满补空行，单页单据补满固定行数）。`rowsPerPage` 初值 12（对齐样单），模板微调时可改。

后端组装、前端渲染——模板字段调整只动后端 VO 组装或模板列宽，不动接口契约。快照回退时 VO 附 `snapshotTime` 字段，预览页据此标注。

## 4. 七类模板字段映射（从样单逐张提取）

### T1 盘盈单/盘亏单（清单式，xlsx 表头）

列：`物料盘点作业编码 | 单据编号 | 日期 | 仓库 | 物料编码 | 物料名称 | 规格型号 | 单位 | 盘盈数量（盘亏单：盘亏数量）| 成本价 | 总成本 | 物料类别`

- **数据源拍板（设计者定，builder 按此执行）**：以**金蝶盘盈单/盘亏单（QTRK/QTCK）分录字段为准**——xlsx 表头即客户现行金蝶导出口径，成本价/总成本取分录自身成本字段，不另查物料档案或即时库存（三个来源三个数字，取错口径客户不认）。WMS 盘点单（PD…）作为**查询入口**：选本地盘点单 → 解析回写的 `erp_bill_no`（逗号合并串，按 QTRK/QTCK 前缀拆分）→ 走金蝶快照链路；也可直接输金蝶单号。未回写的盘点单无可打印单据，提示「该盘点单未回写金蝶，暂无盘盈/盘亏单可打印」。

## 5. 关键决策（含理由）

1. **打印编号一律用金蝶单号**（QTRK/QTCK/XSCK/XSTHD/WMLL…）：与「ERP 是单据信息唯一来源」既有口径一致；本地单号（PD…/XS…）只作为查询入口与「物料盘点作业编码」兜底。
2. **金蝶来源 6 类落快照（含盘盈/盘亏），查询即刷新，失败回退快照并标注时间，无快照才报错**：避免重复打印反复打金蝶接口；报错与「可离线重打」两条口径在失败路径上各归其位（builder 复核提出，设计者拍板）。
3. **WMS 没有的字段（成本价/货款/单价/签名人）以单据自身来源为准、查不到留空**：打印是只读展示，任何字段缺失不得阻断打印（样单本身就有空单价/货款）。盘盈亏成本取 QTRK/QTCK 分录成本字段，不另查物料档案/即时库存。
4. **模板即前端组件、数据由后端统一 VO 组装，分页由后端切段**：加一种单据模板 = 前端一个组件 + 后端一个组装分支 + （金蝶来源）一个 Reader 查询，接口契约不动。
5. **公司名/地址/电话/联次文案为内置常量 + 系统配置可覆盖**（`WmsConfigKey` 加配置项），换主体不用改代码。
6. **签名字段取金蝶单据字段**（审批人/保管员/制单人），取不到留空线——与样单一致。
7. **金蝶单据状态口径（2026-11-09 客户确认）**：**只允许打印已审核（C）单据**，未审核/草稿一律报「单据未审核，不能打印」。查询条件带 `FDocumentStatus=C`；做成常量开关（客户将来要求放开时改配置，当前不提供界面入口）。
