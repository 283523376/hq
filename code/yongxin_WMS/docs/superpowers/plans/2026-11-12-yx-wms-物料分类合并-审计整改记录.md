## 5.1 R2 实现说明（2026-11-12）

两个入口，互不依赖：

1. **定时任务**（自动）：`WmsMasterDataSyncJob.syncForTest()` 里新增「物料分组」步骤，
   顺序为 仓库 → **物料分组** → 分类（旧的代表分组回写）→ 物料 → 仓位属性。
   每步独立 `try/catch`，分组同步失败不影响其余步骤。
   触发条件沿用既有三道闸：`sync.auto` 未关闭 + `master-data.enabled=true` + 金蝶总开关与鉴权就绪。
   `master-data.enabled` 已从写死 `false` 改为 `${KINGDEE_ERP_MASTER_DATA_ENABLED:false}`，
   现场只需设环境变量即可开启，不动 jar。
2. **手动按钮**（兜底）：物料分类树头部新增「同步分组」，调用
   `POST /wms/materialCategory/sync-from-kingdee`（权限 `wms:materialCategory:edit`），
   完成后提示「新建 x，更新 y」并刷新分类树。

注意：
- 生产 `application-prod.yml` 目前没有 `wms.*` 配置（部署方案待定），要在生产开定时任务，
  需同时补 `wms.sync.erp.kingdee.*` 与 `master-data.enabled`，否则任务不会注册。
- 定时任务频率沿用 `WmsConstants.MASTER_DATA_SYNC_JOB_CRON`，本次未改。
