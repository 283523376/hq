## 1. 交付内容

### 1.1 数据库（V3.9.5_60）

| 对象 | 说明 |
| --- | --- |
| `wms_material_category_group` | 金蝶分组 → 分类映射，`UNIQUE (group_number, deleted_at)`，1:N（多分组 → 同一分类） |
| `wms_material_category_merge_bak` | 被合并分类备份（回滚依据，1288 行） |
| `wms_material_merge_bak` | 物料改挂备份（回滚依据，14487 行） |
| 合并口径 | 键 = `category_name + IFNULL(category_type,'')`；存活分类 = 物料数降序 → `create_time` 升序 → `id` 升序 |

脚本幂等（可重复执行，第二次为空操作），顶部 `SET NAMES utf8mb4 COLLATE utf8mb4_general_ci` 与逐表
`COLLATE=utf8mb4_general_ci` 是为了避开 `Illegal mix of collations`（新表默认会落到 `0900_ai_ci`）。

### 1.2 代码（防复发）

| 文件 | 改动 |
| --- | --- |
| `entity/WmsMaterialCategoryGroup`、`mapper/WmsMaterialCategoryGroupMapper` | 新增；不继承 `JeecgEntity`（表里没有 `update_*` / `sys_org_code` 列） |
| `WmsKingdeeMaterialSyncServiceImpl.loadCategoryIdByGroup()` | 先读映射表（跳过指向已删分类的行），再用分类行 `erp_group_number` 兜底 |
| `WmsKingdeeCategorySyncServiceImpl.upsertGroupCategory()` | 命中顺序：映射表 → 分组编码/分类编码 → **同名同类型** → 新建；每个分支都补写映射 |
| 同上 `bindGroup()` / `findMappedCategory()` / `applyMappedType()` | 维护映射；复用已有分类时**不改名称**（只有代表分组能改名） |
| `IWmsMaterialCategoryService.checkNameExists()` + Impl | 手工新增/改名查重，提示「已存在同名同类型的分类「接头」…」 |
| `WmsMaterialCategoryServiceImpl.editCategory()` | 仅当**名称或类型真的变了**才查重；同步回写 `erp_group_number` 不受影响 |
