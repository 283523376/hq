## 前端静态类型检查：本检出**没有**可用门禁（重要限制）

本节更正初稿的一处失实表述。**`pnpm build` 不是类型门禁**——
`package.json:13` 的 build 脚本是 `vite build && esno postBuild.ts && esno copyChat.ts`，**不含 `vue-tsc`**；
且本检出安装的 `vue-tsc@1.8.27` 与 `typescript@5.9.3` 不兼容，实跑即崩：

```
$ npx vue-tsc --noEmit -p tsconfig.json
Search string not found: "/supportedTSExtensions = .*(?=;)/"
```

因此前端改动**没有静态类型校验**（plan 里 Task 10/11/12 写的「pnpm build 类型门禁」在本 checkout 不成立，
`pnpm build` 只做打包）。本专项对前端的验证靠两条替代证据：① 全部 5 个改动页面的**浏览器级 e2e**（见下）；
② 全新上下文审查者逐文件核对 6 个前端文件的字段名/函数签名/导入符号/composable 契约，未发现不一致。
