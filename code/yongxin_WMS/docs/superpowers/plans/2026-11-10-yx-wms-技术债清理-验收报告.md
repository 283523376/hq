## 4. 遗留风险

- **§5-15b 的前置校验只在盘亏侧**：盘盈不查金蝶（盘盈是加库存，不会负库存），这是有意为之。
- **废品仓过滤是应用层过滤**：先按「物料+批次+受托方+所有权」查行，再剔除废品仓库位；
  行数多时多两次库位/仓库查询，量级可接受，但不是 SQL 层 join。
- **`wms:inspection:do` 权限点已随方案 A 逻辑删除**：加注解是 fail-closed，真要用需先恢复权限点与角色授权。
- **V3.9.5_47 建在 `wms_inbound_order` 上的两列保留**：不影响功能，删列反而增加回滚风险。
