# 库存盘点 使用说明

> 设计依据：`docs/superpowers/specs/2026-10-26-yx-wms-outbound-subcontract-sample-stocktake-design.md` §5.3

## 1. 本期边界（2026-10-26 需求方澄清）

- 盘点**只由 WMS 发起**，盘点结果同步到 ERP；
- **ERP → WMS 下发盘点任务、AGV 自动盘点均为后续可能**，本期不实现；
- 项目当前**没有 AGV**，清点一律人工（管理端录入实盘数量）。

## 2. 流程

```
新建盘点（草稿，快照账面）
    → 开始盘点（盘点中，冻结库位）
    → 录入实盘（留空 = 未录入，不当作 0）
    → 差异确认（阈值内 → 差异确认；超阈值 → 复核中）
    → 复核（复核人不得是发起人；通过后回到差异确认）
    → 调整库存（按实盘覆盖 wms_inventory，同时解冻库位）
    → 回写 ERP（盘盈 QTRK / 盘亏 QTCK）
    → 归档（终态）
```

## 3. 冻结与重盘

- 「开始盘点」时范围内库位置 `stocktake_frozen=1`，**出库分配、同库区移库、生产入库上架**
  三条写入路径都会被拦下（报「库位 X 处于盘点冻结」）；
- 在途设备任务不受影响；落账时若涉及冻结库位，对应明细标「需重盘」，
  库位新进的未知物料会插入一条快照重盘行；
- 「调整库存」完成即自动解冻。

## 4. 阈值判定（整单口径）

`(盘盈合计 + 盘亏合计) / 账面合计 × 100 >= 阈值%` → 需复核。

- 账面合计为 0（整库位盘盈）→ 任一差异即复核；
- 阈值 ≤ 0 或未配 → 任一差异即复核（fail-safe）；
- 阈值来源：`wms.stocktake.diff-review-threshold`（默认 5）。

## 5. 配置

```yaml
wms:
  stocktake:
    diff-review-threshold: 5     # 整单复核阈值（%）
    simulate-review: ""          # 仅测试环境：非空时跳过"复核人≠发起人"校验
  sync:
    erp:
      kingdee:
        stocktake:
          stock-code: ""         # 回写用金蝶仓；空 = 回写明确报错（E2）
          writeback-mode: MIS    # MIS=其他出入库单；金蝶建盘点单后可切 STOCK_COUNT
```

> 注意配置键是 `wms.sync.erp.kingdee.stocktake.*`（spec §7 写的 `wms.stocktake.*` 前缀是笔误，
> 以 `@ConfigurationProperties` 实际绑定为准）。

## 6. 菜单与权限

主菜单「库存盘点」（排序 94），子菜单「定期盘点」「周期盘点」共用同一列表页（按类型过滤）。
按钮权限：`wms:stocktake:{list,add,record,confirm,review,adjust,archive}`，admin 已全量授权。

## 7. 已知限制

- 明细实盘录入界面为简化文本框（明细ID,数量,原因），后续迭代可升级为表格行内编辑；
- 盘点单无删除功能（状态机无「作废」态）；如需放弃盘点，走「调整库存→归档」或联系管理员处理数据；
- ERP 回写在 `stock-code` 未配置时明确报错，不会静默成功。
