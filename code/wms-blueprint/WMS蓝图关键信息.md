## 3. 业务域与关键概念

- **物料分类**：半成品、成品、辅料；物料属性含编码、名称、规格、单位、保质期。
  物料需与格子柜系统的「格子与物料类型绑定」逻辑保持一致。
- **工单为主索引**：一切作业以工单为关键索引（切断工单、焊接工单）；全流程可追溯。
- **订单类型**：公司订单、采购订单、委外订单。
- **批次**：入库即生成批次号，支持按批次查询库存与流转记录。
- **格子 / 格子柜**：线边柜侧的最小存储单元；支持格子与工单绑定、拆分/合并调整；
  调整后自动清除工单绑定（格子内有物料时不允许解绑）。
- **库位编码**：库区类型、货架排/列/层、承重、状态（空闲/占用/故障）。
- **不良品 / 废品仓**：不良品与良品物理隔离，记录批次、数量、不良原因；
  是否入线边柜由系统参数配置（不良品存放规则）。
- **库存预警**：按规则监控库存下限、存放超期；预警规则非法拒绝保存，重复触发合并提醒。
- **盘点**：生成盘库单，逐格清点录入；盘点期间发生出入库的格子标记重盘；
  差异超阈值需复核。
- **操作日志**：关键操作（配置变更、绑定/解绑、入库/出库）留痕，存档不可修改，支持查询导出。

## 5. 集成接口

- **上位系统**：ERP / MES / WMS（蓝图原文把「WMS」也列为上位系统之一，
  理解为与外部 WMS/账务系统同步）。方向：WMS 汇总柜内库存与出入库记录后按接口推送。
  同步判定：成功→记录同步日志；失败→自动重试→告警；有差异→生成差异清单交管理员核对。
- **设备层**：WMS 下发任务给 **WCS**，由 WCS 调度堆垛机（半成品立库）与 SCR 机器人
  （成品敏捷仓）；同时采集设备状态（在线/离线/故障）、开柜记录、门锁状态。
- **开柜记录**：格子柜设备上报（时间、人员、格子），校验完整性后入库留痕，供对账与审计。

## 6. 通用约定（异常处理的共同模式）

- 同步/推送/开柜失败：**自动重试 3 次 → 仍失败则告警并记录日志**。
- 库存/库位/格子不足、设备故障、格子异常：**告警并转人工**。
- 单据/工单/物料不存在：**提示并拒绝**该项操作。
- 数量异常：提示「数量超出范围」。
- 无匹配记录：提示「无匹配记录，请更换条件」；导出失败保留任务记录、支持重导。
- 幂等与幂等性提示：编码/订单号/库位编码重复 → 提示已存在并拒绝保存。
